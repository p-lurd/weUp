## Description

An api monitoring tool.
This is for selfhosting. To do that, checkout the .env.example for environmental variables when deplying the image.


## Project setup

```bash
# Install dependecies
$ npm install

# runn code in development
$ npm run dev

# To build
$ npm run build
```
